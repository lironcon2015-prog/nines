# הספרייה המשותפת — הקמה פעם אחת

הסקריפט שבתיקייה הזאת (`Code.gs`) הופך תיקיית דרייב שלך לספרייה שמשותפת בין
שני טלפונים. **אין כאן התחברות לחשבון, לא אצלך ולא אצל הילד** — הסקריפט נפרס
"בשמך", ולכן הוא רץ בהרשאות שלך, ושני הצדדים רק פונים לכתובת עם קוד.

הוא עושה שלושה דברים:

1. **מחזיק את הספרייה** — `library.json` ותיקיית `posters` בתיקייה שלך.
2. **מביא תצוגה מקדימה** — שם, תמונה וקובץ הווידאו של כל קישור שמוסיפים.
   זה מחליף את ארבעת השירותים החינמיים שהאפליקציה נשענה עליהם.
3. **שומר את התמונות** — מושך אותן בעצמו, וכך הן לא פגות ולא תלויות ב-CORS.

---

## ההקמה — ארבע פעולות

אין מה למלא בקוד ואין מה ליצור מראש. הסקריפט יוצר לבד את התיקייה בדרייב ואת
שני הקודים, ושומר אותם במאפייני הפרויקט.

### 1. הדבק את הסקריפט

[script.google.com](https://script.google.com) → **פרויקט חדש** → מחק את מה שיש
שם והדבק את כל התוכן של `Code.gs`.

*(אם בא לך לשנות את השם שמופיע בפס העליון בשני הטלפונים — `LIBRARY_NAME` בראש
הקובץ. זה היחיד שם, ואפשר גם פשוט להשאיר.)*

### 2. הרץ `setup` פעם אחת

בחר למעלה את הפונקציה **setup** ולחץ **▶ הפעלה**. אשר את ההרשאות — זה החשבון
שלך מול הסקריפט שלך.

> אם מופיע "האפליקציה לא מאומתת" — **מתקדם** → **המשך אל…**. זו האזהרה הרגילה
> של גוגל על סקריפט שלא עבר אימות ציבורי.

ביומן שנפתח למטה יופיעו התיקייה שנוצרה ו**קוד הכתיבה** שלך:

```
  ✓ הכול מוכן.

  התיקייה נוצרה בדרייב שלך:
     תשיעיות  —  https://drive.google.com/…

  ┌─────────────────────────────────────────────
  │ קוד הכתיבה — זה מה שמדביקים באפליקציה שלך:
  │
  │    w-3f9c1a7b204e8d65c1af
  │
  │ אל תשלח אותו לאף אחד.
  └─────────────────────────────────────────────
```

קוד הקריאה נוצר גם הוא, והאפליקציה שותלת אותו לבד בתוך הקישור שנשלח לילד —
אין צורך להעתיק אותו.

שכחת את קוד הכתיבה? הרץ שוב `setup`, הוא ידפיס את אותו קוד. דלף? הרץ
`resetCodes` — הספרייה עצמה אינה נוגעת, והילד יצטרך קישור הצטרפות חדש.

### 3. פרוס

**פריסה** → **פריסה חדשה** → גלגל השיניים → **אפליקציית אינטרנט**:

| שדה | ערך |
|---|---|
| הרצה בשם | **אני** (החשבון שלך) |
| מי יש לו גישה | **כל מי שיש לו הקישור** |

לחץ **פרוס** והעתק את הכתובת שמסתיימת ב-`/exec`.

### 4. חבר את שני הטלפונים

**אצלך:** באפליקציה, מסך הבית → **ספרייה משותפת** → הדבק את הכתובת ואת קוד
הכתיבה → **התחבר**. הספרייה שכבר יש לך על המכשיר תעלה לדרייב — היא לא נמחקת.

**אצל הילד:** באותו מסך אצלך יופיע **הקישור לשליחה**. שלח אותו בוואטסאפ, הוא
לוחץ ומאשר. הקישור נושא בתוכו את הכתובת ואת קוד הקריאה — הוא לא מקליד כלום.

## מה כל צד יכול

|  | אתה (קוד כתיבה) | הילד (קוד קריאה) |
|---|---|---|
| לראות את הספרייה | ✓ | ✓ |
| לנגן סרטון | ✓ | ✓ |
| להוסיף · לערוך · למחוק | ✓ | ✗ |
| לשנות כותרות | ✓ | ✗ |

האיסור נאכף **בסקריפט** ולא רק במסכים: בקשת כתיבה שמגיעה עם קוד קריאה נדחית
בשרת. הסתרת הכפתורים באפליקציה היא נוחות בלבד.

## עדכון הסקריפט בהמשך

**פריסה** → **נהל פריסות** → העיפרון → **גרסה: חדשה** → **פרוס**.

⚠️ **אל תיצור פריסה חדשה.** פריסה חדשה מקבלת כתובת אחרת, ושני הטלפונים
מאבדים את הספרייה וצריכים להתחבר מחדש.

## מכסות

הכול בתוך המכסה החינמית של חשבון גוגל רגיל, בפער גדול:

| מה | המכסה | מה אנחנו צורכים |
|---|---|---|
| בקשות יוצאות (`UrlFetchApp`) | 20,000 ליום | אחת לכל סרטון שמוסיפים, ואחת לכל תמונה |
| זמן ריצה | 90 דקות ליום | שבריר שנייה לסנכרון |
| אחסון בדרייב | 15GB | כ-45KB לתמונה |

## כשמשהו לא עובד

**בדיקה מהירה מהדפדפן.** הדבק בשורת הכתובת:

```
https://script.google.com/macros/s/…/exec?op=ping&k=הקוד-שלך
```

- `{"ok":true,"mode":"owner",…}` — הכול תקין.
- `{"ok":false,"error":"הקוד אינו מוכר"}` — הקוד לא תואם למה שבסקריפט.
- דף שגיאה של גוגל — הפריסה לא קיימת, או שהגישה אינה "כל מי שיש לו הקישור".

**באפליקציה** יש `בדוק את השירותים` בטופס ההוספה — הוא מדווח מה הסקריפט ענה
ותוך כמה זמן, לצד ארבעת השירותים החיצוניים.

**"הכתובת לא החזירה תשובה תקינה"** באפליקציה פירושו כמעט תמיד כתובת של פריסה
שכבר לא קיימת — ראה "עדכון הסקריפט" למעלה.
