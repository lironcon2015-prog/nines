# הספרייה המשותפת — הקמה פעם אחת

הסקריפט שבתיקייה הזאת (`Code.gs`) הופך תיקיית דרייב שלך לספרייה שמשותפת בין
שני טלפונים. **אין כאן התחברות לחשבון, לא אצלך ולא אצל הילד** — הסקריפט נפרס
"בשמך", ולכן הוא רץ בהרשאות שלך, ושני הצדדים רק פונים לכתובת עם קוד.

הוא עושה שלושה דברים:

1. **מחזיק את הספרייה** — `library.json` ותיקיית `posters` בתיקייה שלך.
2. **מביא תצוגה מקדימה** — שם, תמונה וקובץ הווידאו של כל קישור שמוסיפים.
   זה מחליף את ארבעת השירותים החינמיים שהאפליקציה נשענה עליהם.
3. **שומר את התמונות** — מושך אותן בעצמו, וכך הן לא פגות ולא תלויות ב-CORS.

---

## ההקמה — כעשר דקות

### 1. תיקייה בדרייב

צור תיקייה חדשה בשם **תשיעיות**. פתח אותה, והעתק את המזהה מהכתובת:

```
https://drive.google.com/drive/folders/1AbCdEfGhIjKlMnOpQrSt
                                       └──────── זה המזהה ────────┘
```

### 2. הסקריפט

היכנס ל-[script.google.com](https://script.google.com) → **פרויקט חדש** →
מחק את מה שיש שם והדבק את כל התוכן של `Code.gs`.

### 3. ארבע השורות בראש הקובץ

```js
var FOLDER_ID    = 'המזהה מסעיף 1';
var WRITE_CODE   = 'קוד ארוך שרק אתה מחזיק';
var READ_CODE    = 'קוד ארוך אחר — זה מה שנשלח לילד';
var LIBRARY_NAME = 'הספרייה שלנו';
```

**הקודים הם המפתחות.** מי שמחזיק בקוד נכנס, ואין מעליו סיסמה — לכן שניהם
צריכים להיות ארוכים ולא ניחושים. משהו כמו `nesher-8412-kadur-shesh` עדיף על
`1234`. שניהם חייבים להיות שונים זה מזה.

### 4. פריסה

**פריסה** → **פריסה חדשה** → גלגל השיניים → **אפליקציית אינטרנט**:

| שדה | ערך |
|---|---|
| הרצה בשם | **אני** (החשבון שלך) |
| מי יש לו גישה | **כל מי שיש לו הקישור** |

לחץ **פרוס**, אשר את ההרשאות (זה החשבון שלך מול הסקריפט שלך, פעם אחת), והעתק
את הכתובת שמסתיימת ב-`/exec`.

> אם מופיע "האפליקציה לא מאומתת" — לחץ **מתקדם** → **המשך אל…**. זה הפרויקט
> שלך בחשבון שלך, וזו האזהרה הרגילה של גוגל על סקריפט שלא עבר אימות ציבורי.

### 5. חיבור הטלפון שלך

באפליקציה: מסך הבית → **ספרייה משותפת** → הדבק את הכתובת ואת `WRITE_CODE` →
**התחבר**. הספרייה שכבר יש לך על המכשיר תעלה לדרייב — היא לא נמחקת.

### 6. הטלפון של הילד

באותו מסך אצלך יופיע **הקישור לשליחה**. שלח אותו בוואטסאפ. הוא לוחץ עליו,
האפליקציה נפתחת במסך ההצטרפות, והוא מאשר. זהו.

הקישור נושא בתוכו את הכתובת ואת `READ_CODE` — הילד לא מקליד כלום.

## מה כל צד יכול

|  | אתה (`WRITE_CODE`) | הילד (`READ_CODE`) |
|---|---|---|
| לראות את הספרייה | ✓ | ✓ |
| לנגן סרטון | ✓ | ✓ |
| להוסיף · לערוך · למחוק | ✓ | ✗ |
| לשנות כותרות | ✓ | ✗ |

האיסור נאכף **בסקריפט** ולא רק במסכים: בקשת כתיבה שמגיעה עם קוד קריאה נדחית
בשרת. הסתרת הכפתורים באפליקציה היא נוחות בלבד.

## עדכון הסקריפט בהמשך

**פריסה** → **נהל פריסות** → העיפרון → **גרסה: חדשה** → **פרוס**.

⚠️ **אל תיצור פריסה חדשה.** פריסה חדשה מקבלת כתובת אחרת, ושני הטלפונים
מאבדים את הספרייה וצריכים להתחבר מחדש.

## כשמשהו לא עובד

**בדיקה מהירה מהדפדפן.** הדבק בשורת הכתובת:

```
https://script.google.com/macros/s/…/exec?op=ping&k=הקוד-שלך
```

- `{"ok":true,"mode":"owner",…}` — הכול תקין.
- `{"ok":false,"error":"הקוד אינו מוכר"}` — הקוד לא תואם למה שבסקריפט.
- דף שגיאה של גוגל — הפריסה לא קיימת, או שהגישה אינה "כל מי שיש לו הקישור".

**באפליקציה** יש `בדוק את השירותים` בטופס ההוספה — הוא מדווח מה הסקריפט ענה
ותוך כמה זמן, לצד ארבעת השירותים החיצוניים.

**"הכתובת לא החזירה תשובה תקינה"** באפליקציה פירושו כמעט תמיד כתובת של פריסה
שכבר לא קיימת — ראה "עדכון הסקריפט" למעלה.
